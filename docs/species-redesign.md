# 동물 종·등급 중심 개편

도감은 동물 종마다 모든 모습을 묶어 표시한다. 보관함은 동물 종 선택과 등급 필터를 제공하고 기본 정렬도 종별로 묶는다. 기존 컬렉션 ID와 보유 수량, 과거 훈장·업적은 유지한다.

## 2026-10-24 보상·획득 경로 조정

- 동물별 첫 획득과 등급별 첫 달성의 뽑기권: 노말 3장, 레어 4장, 에픽 5장, 유니크 6장, 레전더리 7장, 히든 10장. 이벤트 등급과 누적·완성 보상은 기존 값 유지.
- 이미 지급한 뽑기권과 수령 기록은 유지한다. 미수령 보상부터 새 금액을 사용한다.
- 현재 노말·프리미엄 뽑기만 운영한다. 노말 뽑기는 노말 12종, 프리미엄 뽑기는 노말 92%·프리미엄 8%이며 각 컬렉션 안에서는 균등 추첨한다. 가격·포스터는 유지한다.
- 가을·바다·고양이 뽑기는 일시 중지한다. 히든·이벤트·고양이도 현재 두 뽑기에서는 나오지 않는다.
- 기존 레어·에픽·유니크·레전더리와 고양이의 같은 등급 모습은 진화 전용이다. 프리미엄 컬렉션은 레어 등급이지만 뽑기 대상으로 유지한다.
- 노말 → 레어 → 에픽 → 유니크 → 레전더리, 고양이 노말 → 같은 품종의 레어 → 에픽 → 유니크 → 레전더리로 진화한다. 프리미엄 동물은 진화하지 않는다.
- 기존 evolution_* 동물도 보유·진화 경로를 유지한다. 기존 동물 ID·이미지·보유량·과거 훈장·업적을 삭제하지 않는다.
- 진화 전용 동물은 뽑기·교배·합성·재활용의 결과로 얻을 수 없다. 이미 받은 알의 부화는 유지한다. 아기 시리즈는 뽑기에서 계속 제외한다.
- 운영 카탈로그는 scripts/publish-species-redesign.cjs --draw-balance로 사전 계획을 만든 뒤 같은 옵션에 --apply를 추가해 버전 전제조건과 함께 원자적으로 게시한다.
