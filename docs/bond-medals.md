# 친밀도와 훈장

- 보관함: 동물 / 훈장 / 기타(코인·뽑기권).
- 훈장 장착: 마이페이지에는 대표 훈장과 '훈장 장착하러 가기' 바로가기만 표시. 바로가기는 보관함의 훈장 탭을 직접 열며, 보유 훈장 목록에서 장착·교체·해제. 내 프로필과 친구 프로필의 사진/닉네임 아래에 대표 훈장 표시. 영구 훈장은 수령 기록을 검사하고, 랭킹 훈장은 실시간 1위 자격이 사라지면 표시하지 않음.
- 프로필: 사진과 닉네임을 최상단에 표시. 동물은 중복 보유 수량을 제외한 종류 수(종)로 집계하며, 높은 등급부터 6종 미리보기와 더보기/접기를 제공. 보유 훈장은 6개 미리보기. 훈장 보관함은 수령 가능한 훈장 3개 미리보기와 획득 조건 펼치기를 제공.
- 컬렉션 훈장: 각 컬렉션의 동물을 모두 보유한 상태에서 도감 또는 훈장 보관함에서 수령. 업적 뽑기권 수령과 독립적이며, 수령 후 판매해도 영구 보유.
- 활동 훈장: 누적 10,000·100,000걸음, 뽑기 100회, 부화·진화·합성·재활용 각각 10회. 직접 수령, 영구 보유.
- 랭킹 훈장: 걸음·부화·진화·합성·재활용·등급별 보유 종류의 현재 1위. 랭킹 문서의 실시간 변경으로 보유자가 바뀌며 영구 훈장으로 저장하지 않음. 0점은 제외. 동점은 UID 오름차순으로 한 명에게 부여. 랭킹 화면의 공동 순위 표시는 유지.
- 친밀도: 대표 동물별로 100걸음당 1점 + 대표 동물로 설정한 시간 1시간당 1점. 앱 종료 중에도 시간 누적. 전환 시 이전 동물의 시간·걸음을 트랜잭션으로 정산하여 보관. 기존 대표 동물은 업데이트 이후 최초 접속부터 시작. 진화한 동물은 별도 동물로 취급.
- 단계: 첫 만남(0), 익숙한 사이(100), 든든한 친구(500), 마음의 단짝(1,500), 평생의 동반자(4,000). 프로필에 동물 이름과 계정 닉네임을 넣은 단계별 문구 표시.

## 저장과 규칙

`users/{uid}/medals/{id}`에는 서버 발급 시각만 저장. Firestore 규칙에서 조건 충족 여부를 검사하며 수정·중복 수령을 금지. 계정 삭제 이후에만 훈장 삭제 허용.

`bonds/{uid}`에 동물별 누적 시간·걸음, 현재 대표 동물과 시작 시각·시작 걸음을 기록. 서버 시각과 현재 프로필을 이용해 정산을 검사. 휴대폰 시계 차이를 위해 정산 시 5초 허용.

`medalDisplays/{uid}`에 대표 훈장 선택값과 서버 저장 시각을 기록. 랭킹 훈장 선택값은 선호 설정이며 소유권의 근거가 아님. 화면에서는 항상 현재 랭킹에 따른 보유 훈장과 대조해 표시. 친구에게 공개되고, 변경은 본인만 가능. 계정 탈퇴 시 함께 삭제.

규칙 원본은 `scripts/bond-medals.rules`; `node scripts/generate-gacha.js`로 `firestore.rules`에 포함. **실제 앱에서 저장하려면 업데이트한 Firestore 규칙 배포가 필요함.**

랭킹은 기존 클라이언트 동기화 문서를 기준으로 판정. 정확한 우승자 판정을 위해 기존 임의의 500명 제한을 제거. 사용자 규모가 커지면 서버 집계로 전환할 것.
