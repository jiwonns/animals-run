## 최신 업데이트 · 2026년 10월 19일

- **커뮤니티 오픈** — 홈 → 커뮤니티에서 자유·자랑·질문·산책 이야기를 나눠요. 글쓰기, 보유 동물 첨부, 댓글, 좋아요를 사용할 수 있어요.
- **친구 프로필** — 랭킹·지도에서 프로필 사진을 누르거나 커뮤니티 작성자를 누르면 대표 동물, 누적 걸음, 보유 동물과 활동 기록을 볼 수 있어요.
- **포스터 수정** — 십이지신 노말 컬렉션 토끼의 여분 귀를 제거하고 오른쪽 귀를 접힌 모양으로 다듬었어요.

## 1. 갤럭시 (안드로이드) — APK 설치

<a href="https://github.com/jiwonns/animals-run/releases/download/v1.0.0-beta/AnimalsRun-beta.apk"><img src="https://github.com/jiwonns/animals-run/releases/download/v1.0.0-beta/AnimalsRun-beta-QR.png" width="160" alt="최신 베타 APK 다운로드 QR" align="right" /></a>

1. 갤럭시 카메라로 오른쪽 QR을 찍거나, 위의 **APK 다운로드**를 눌러 `AnimalsRun-beta.apk`를 받아요.
2. 다운로드한 파일을 눌러 열어요.
3. "출처를 알 수 없는 앱" 안내가 나오면 **설정 → 이 출처 허용**을 켜고 돌아와서 **설치**를 눌러요.
4. "Play 프로텍트" 경고가 뜨면 **세부정보 더보기 → 무시하고 설치**를 눌러요. 정식 스토어 앱이 아니라서 뜨는 경고예요.
5. 설치가 끝나면 **Animals Run** 아이콘이 생겨요.

업데이트할 때는 **기존 앱을 삭제하지 말고 덮어 설치**해주세요. 앱 아이콘으로 바로 실행할 수 있고 개발 서버는 필요 없어요.

## 2. 아이폰 — Expo Go로 접속

아이폰은 **[웹 버전](https://animalsrun-2571c.web.app)** 으로 바로 이용할 수 있어요. Expo Go는 개발자와 함께 테스트할 때 이용해주세요.

<img src="docs/qr-expo-go.png" width="160" alt="Expo Go 설치 QR" />

1. App Store에서 **Expo Go** 앱을 설치해요.
2. 개발자에게 **현재 실행 중인 서버의 접속 QR**을 받아요.
3. 아이폰 **기본 카메라**로 QR을 찍고 Expo Go로 열어요.

> [!WARNING]
> Expo Go 접속에는 호환되는 앱 버전과 실행 중인 개발 서버가 필요해요. 서버를 다시 켜면 접속 주소가 바뀔 수 있어 예전 QR이 작동하지 않을 수 있어요. 연결되지 않으면 웹 버전을 이용하거나 개발자에게 현재 QR을 요청해주세요.

## 3. 웹 버전 — 사파리/크롬으로 바로 접속

<img src="docs/qr-web.png" width="160" alt="웹 버전 QR" align="right" />

설치 없이 브라우저로 바로 해볼 수 있어요. Expo Go가 설치되지 않는 옛날 아이폰도 돼요.

1. 카메라로 오른쪽 QR을 찍거나 **[animalsrun-2571c.web.app](https://animalsrun-2571c.web.app)** 을 열어요.
2. 사파리 **공유 버튼 → 홈 화면에 추가**를 누르면 앱처럼 아이콘이 생겨요.
3. 지도 탭에서 위치 허용 창이 뜨면 **허용**을 눌러주세요.

> [!NOTE]
> 웹 버전은 **걸음 수를 셀 수 없어요** (브라우저가 걸음 센서를 지원하지 않아요). 뽑기·합성·지도·랭킹 등 나머지는 앱과 똑같고, 같은 계정이라 앱과 웹을 오가며 써도 돼요.

## 4. 시작하기

1. **회원가입**에서 아이디, 닉네임, 비밀번호, 생년월일을 입력해요.
   - 아이디: 로그인용 (영문 소문자·숫자·`_` 4~20자)
   - 닉네임: 지도와 랭킹에 보이는 이름 (한글·영문·숫자·`_` 2~10자)
2. 가입하면 **100코인과 내 띠 동물**을 선물로 받아요.
3. 위치와 동작(걸음) 권한을 물어보면 **허용**해주세요. 걸음 수가 코인으로 바뀌고, 지도에 내 위치가 보여요.

## 5. 이렇게 놀아요

- **뽑기** — 코인이나 티켓으로 동물을 뽑아요. 배너마다 나오는 동물이 달라요.
- **홈** — 알 부화, 합성, 진화, 교배, 재활용으로 더 높은 등급의 동물을 만들어요. 커뮤니티도 홈에서 들어갈 수 있어요.
- **커뮤니티** — 글에 보유 동물을 첨부하고 댓글·좋아요로 친구들과 이야기해요. 내가 쓴 글과 댓글은 삭제할 수 있어요.
- **보관함** — 모은 동물과 도감을 볼 수 있어요.
- **지도·랭킹** — 친구의 프로필 사진을 누르면 대표 동물, 걸음, 보유 동물과 활동 기록을 볼 수 있어요.
- **마이페이지** — 닉네임·대표 동물 변경, 업적 보상, 랭킹, 뽑기 기록.

## 6. 테스트하면서 봐주면 좋은 것

- 앱이 멈추거나 꺼지는 곳, 버벅이는 화면
- 걸음 수가 제대로 쌓이는지, 지도에 위치·동물 얼굴이 잘 뜨는지
- 커뮤니티 글쓰기·댓글·좋아요가 잘 반영되는지, 프로필 사진을 눌렀을 때 해당 친구 정보가 뜨는지
- 확률이나 보상이 너무 짜거나 후한 부분
- 헷갈리는 문구나 버튼, "이런 게 있으면 좋겠다" 싶은 것

문제가 생기면 **어떤 폰**에서 **어느 화면**에서 **무엇을 눌렀을 때** 생겼는지와 스크린샷을 [Issues](https://github.com/jiwonns/animals-run/issues)에 남기거나 개발자에게 보내주세요.

## 7. 알아두세요

- 베타 버전이라 정식 출시 전에 데이터(코인, 동물)가 초기화될 수 있어요.
- 평소 쓰는 비밀번호와 다른 비밀번호를 써주세요.
- 새 버전이 나오면 갤럭시는 새 APK를 덮어 설치하고, 웹은 새로고침해주세요. Expo Go는 실행 중인 개발 서버의 변경 사항을 불러와요.

## 개발자용

Expo SDK 58 · Expo Router · Firebase (Auth, Firestore)

```bash
npm install
cp .env.example .env               # Firebase 웹 앱 설정값 입력
cp .firebaserc.example .firebaserc # Firebase 프로젝트 ID 입력
npm run gacha                      # 이미지 최적화 + firestore.rules / 뽑기 상수 생성
npx expo start
```

- 뽑기 데이터: `assets/gacha/` → `npm run gacha`로 `firestore.rules`와 `src/constants/gacha.generated.ts` 생성
- 규칙 배포: `npx firebase-tools deploy --only firestore:rules`
- 웹 배포: `npx expo export -p web --output-dir web-build && npx firebase-tools deploy --only hosting`
